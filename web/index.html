这个书库还是空的

书库根目录下，一个本子一个子目录：
· 目录里有 case.yml → 按结构化本子读；
· 没有 case.yml → 按资料夹读（PDF / 图片 / 文档都行）。
也可以点上面「＋ 目录」，把别处的本子合辑指过来。

怎么开

  1. 选一种玩法。
  2. 点一张玩法卡：这一页直接弹出对局室，引擎就在这一页里应答，不用回会话。
  3. 下面换动作、填内容、回车提交；想推倒重来点右上「重新开一局」。

这七种玩法来自 dsh-xgame：真相封在插件侧，NPC 台词要过泄密审计。

新窗口打开

新建一本

先给骨架取个名字。真正的本子内容，建完在文件夹里改 case.yml。

局域网

开了以后，同一 Wi-Fi / 局域网里的手机、平板、别的电脑，用下面的链接就能直接开案卷台和对局室。钥匙就写在链接里，别贴到公网；用完想关就把开关拨回「关」。
